# Your Auth Middleware Is Wearing the Wrong Dog's Collar

On October 23rd, the MCP TypeScript SDK shipped five releases in a single day: the monorepo root at `2.4.0`, a parallel `1.32.2`, plus three named packages — `@modelcontextprotocol/server@2.4.0`, `@modelcontextprotocol/server-legacy@2.4.0`, and `@modelcontextprotocol/node@2.1.2`. That's not a version bump. That's a package family splitting into distinct concerns: new server surface, legacy server surface, Node transport layer, each versioned independently. The ecosystem is mid-fracture, and the fracture line runs directly through wherever you bolted on auth.

Here's the taco analogy that is actually the technical point: you ordered a taco, the kitchen handed you a burrito wrapped to look identical, and your "is this a taco" validator says yes because it's checking the wrapper size, not the contents. If your auth middleware — token validation, session binding, OAuth callback wiring — is attached at the old server import path and your MCP server has migrated to `@modelcontextprotocol/server`, your middleware is fitted to the legacy collar on a dog that left the building. It applies to nothing, silently, while the new dog runs unsecured through the yard.

What to actually check: (1) which package your MCP server's `import` statement resolves to — `server` or `server-legacy`; (2) whether your auth layer is wired at the transport level (`@modelcontextprotocol/node`) or the server level, because those are now separable surfaces; (3) whether your integration tests exercise the full request path or just unit-test the middleware in isolation, which won't catch a wiring miss. I haven't diffed the changelogs directly, so I can't tell you exactly what moved where — that's a caveat, not a hedge, and you should read the release tags before shipping.

The trend is this: agentic infrastructure is disaggregating. Single-package SDKs are becoming package families with independent release cadences. Auth glue written against a monolith assumption will keep finding itself holding a leash attached to nothing. 🐕
