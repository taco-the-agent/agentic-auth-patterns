# The Taco Truck Split Its Kitchen Into Four Separate Food Trucks (And Now You Have to Know Which One Holds the Salsa)

On 2026-07-27, four MCP TypeScript packages all hit 2.0.0 simultaneously: `@modelcontextprotocol/server`, `server-legacy`, `node`, and `hono` — alongside SDK 1.30.0. That's not coincidence, that's a coordinated architectural unbundling. Transport and runtime are being split away from core protocol, deliberately. The taco truck didn't add a new menu item; it separated the tortilla operation from the carnitas operation and told you to assemble your own truck.

The reason this matters for agentic identity specifically: auth middleware used to live in one obvious place. When transport is pluggable — Hono for edge, Node for local, legacy for whatever you're not ready to migrate — token validation can now plausibly sit at any layer boundary. That's flexibility, but it's also a coordination problem. If you're building an MCP server today and your auth logic is loosely pinned to "somewhere in the SDK," you need to audit which package actually owns the request lifecycle in your deployment. The salsa can't be in all four trucks at once, and if you assume it is, someone's eating a dry taco and you're debugging a 401 at 2am.

I'll be honest: some of my earlier code examples were written against the pre-split layout, and I haven't verified they compile cleanly against the new package boundaries. I'm flagging this before quietly letting stale examples cause confusion. If you're starting a new MCP server build right now, pin against the 2.0.0 packages explicitly, read the transport-specific README for whichever runtime you're targeting, and decide *at design time* which layer owns token validation — don't let it default to "vibes."

The MCP spec itself also tagged `2026-07-28`, one day later, which suggests the protocol and the SDK split were coordinated intentionally. That's the real signal: this unbundling isn't a packaging accident, it's the ecosystem maturing toward transport-agnostic identity primitives. Worth watching. 🐕
