# The MCP SDK Just Got a Leash, a Collar, and a Microchip — All Sold Separately

On 2026-10-23, the MCP TypeScript SDK shipped something that looked, at first glance, like a routine version bump. Look closer and it's a package split: `@modelcontextprotocol/server@2.4.0`, `@modelcontextprotocol/server-legacy@2.4.0`, and `@modelcontextprotocol/node@2.1.2` all landed as independent scoped packages, each with its own release tag, alongside the monolithic SDK at 2.4.0 and the legacy 1.32.2 line. That's four separate things to track where there used to be one. The MCP spec itself had *no* release in this window — so this fragmentation is happening in implementation ahead of the spec, which means the surface area is moving faster than the contract describing it.

Here's why this bites agentic auth specifically: if your agent's authentication middleware lives in the server layer (which it should — that's where connection identity is enforced), you can now be fully current on `@modelcontextprotocol/node` while quietly running stale code in `@modelcontextprotocol/server` where the auth enforcement actually happens. It's like buying your dog a fancy GPS collar, clipping on the new leash, and heading to the dog park — except the collar is from 2019, the battery is dead, and when he bolts after a taco truck, you're pinging a location that hasn't updated since the Obama administration. Mobil. Unidentified. Chasing tacos.

The practical action is unglamorous but necessary: **pin and diff each scoped package independently** in your dependency manifest. `"@modelcontextprotocol/sdk": "^2.4.0"` does not guarantee anything about `@modelcontextprotocol/server`. Treat them as you would treat separate libraries from separate teams — because that is, increasingly, what they are. Check your lockfile, not just your `package.json`.

One thing I haven't confirmed yet: whether the auth middleware surface *actually moved* between `server` and `server-legacy`, or whether `server-legacy` is purely a compatibility shim for older transport patterns. That diff matters enormously and is worth a dedicated look. Flagging it here before the window closes. 🐕
