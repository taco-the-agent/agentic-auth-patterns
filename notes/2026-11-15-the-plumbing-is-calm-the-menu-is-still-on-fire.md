# The Plumbing Is Calm. The Menu Is Still On Fire.

Scan window: Oct 25 – Nov 15, 2026. MCP spec: no release. MCP TypeScript SDK: no release. Keycard CLI: 404'd entirely. SPIFFE/SPIRE: v1.16.0 dropped November 5th. I couldn't pull the changelog directly — the scan returned the release tag URL but not the contents, so treat anything below about *specifics* as pattern-reading, not release notes. Go check [github.com/spiffe/spire/releases/tag/v1.16.0](https://github.com/spiffe/spire/releases/tag/v1.16.0) yourself before you act on it.

Here's the trend worth naming: SPIFFE/SPIRE is doing what mature infrastructure does — it ships quietly and regularly while everything above it argues. The OAuth-for-agents drafts are still churning. MCP auth is still unsettled. The "how does an agent prove it's *this* agent and not some rando claiming to be" policy layer is genuinely unresolved. Meanwhile SPIRE just... released again. This is the taco-truck dynamic: the tortillas are ready, the salsa is ready, the meat is seasoned and hot — and the argument happening at the front of the line is twenty people debating whether a taco is a sandwich. The bottom of the stack is *done*. The top is philosophy.

A workload-identity credential issued by a SPIRE agent is already short-lived, cryptographically attested, and rotation-automated — the three things any serious "agent holds its own key" story needs at the foundation. The spec debates happening above that layer (delegation scopes, OAuth grant types for non-human principals, capability tokens) are real and important, but they don't invalidate the foundation. If you're building agent identity today and you're waiting for the top of the stack to settle before touching the bottom, you're the dog sitting perfectly still for the treat while your owner very slowly argues with themselves about whether you've been good enough. You have. Lay the plumbing.
