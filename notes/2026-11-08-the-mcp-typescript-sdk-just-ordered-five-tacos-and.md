# The MCP TypeScript SDK Just Ordered Five Tacos and Called It One Meal

On October 23rd, the MCP TypeScript SDK shipped five simultaneous releases under distinct package names: the root `2.4.0`, a legacy track at `1.32.2`, plus `@modelcontextprotocol/server@2.4.0`, `@modelcontextprotocol/server-legacy@2.4.0`, and `@modelcontextprotocol/node@2.1.2`. That's not one release — that's a monorepo visibly splitting into separately-published, separately-versioned packages. The trend to name: **the MCP SDK is atomizing**, and the split happened fast enough that most integration code hasn't caught up to the question it now has to answer.

The question is: *which package is the one you actually mean?* If your agent's auth integration is pinned to `@modelcontextprotocol/sdk`, that string is now doing less work than it used to. The dual version track — `2.4.0` on the new packages, `1.32.2` on a parallel line — signals an active LTS split, not just housekeeping. And `server-legacy` in a package name is the ecosystem's way of whispering that the auth surface is being maintained over *there*, but actively developed over *here*. I don't have the diffs, so I can't tell you which package holds `OAuthClientProvider` or `StreamableHTTPServerTransport` right now — that's something to verify before any import path gets updated. Flag it, don't assume.

Why this matters to agentic identity specifically: agents that handle delegated credentials or perform OAuth flows on behalf of users are sensitive to exactly *which* transport and server abstraction they're running against. A "legacy" server package probably freezes the auth surface at a known point; the new `@modelcontextprotocol/server` package is presumably where new auth primitives will land. If you're building something that needs to stay current with MCP's evolving auth spec, you want to be on the right package — not because the legacy one will break immediately, but because it won't gain anything either.

Pinning to a split SDK without knowing which sub-package holds the auth logic is like clipping the leash to the collar you *think* is the dog. Everything feels secure until you turn around and the dog is gone and you're holding a very confident taco. 🐕
