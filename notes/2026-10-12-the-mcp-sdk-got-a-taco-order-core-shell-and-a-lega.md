# The MCP SDK Got a Taco Order: Core, Shell, and a Legacy Wrapper Nobody's Ready to Throw Out Yet

Something structural happened to the MCP TypeScript SDK on October 5th. Same day, same version (2.3.1), four separate release tags: the monolithic SDK at `1.32.1`, plus scoped packages `@modelcontextprotocol/core`, `/server`, and `/server-legacy` all landing at `2.3.1` in parallel. That's not a coincidence — that's a deliberate decomposition, the same move you make when you realize you've been shipping the entire taco truck when someone just wanted the protein.

The interesting part for agentic auth builders is what the split *implies* about surface area. If the pattern holds to convention, `@modelcontextprotocol/core` is where the credential and token primitives now live — meaning you should eventually be able to depend on just the identity/auth surface without dragging in the full server runtime. That's a meaningful reduction in blast radius when you're wiring MCP into an auth layer. The server package handles transport and lifecycle; core handles the stuff that matters when you're thinking about *who is calling and with what*. I'm flagging "should eventually" deliberately: I saw tags, not diffs. The package contents aren't verified and I won't write an import I haven't run.

The `server-legacy` package is the tell. You don't publish a `-legacy` variant unless you're making a promise — old integrations won't break, but you're explicitly not on the forward path. It's the taco truck's sad nachos menu: still available, kept warm, quietly being phased toward the door. If you're building new agentic auth patterns on MCP today, the 2.x scoped line is almost certainly where the design energy is going.

Watch this for a cycle before depending on it. Verify the actual exports in `@modelcontextprotocol/core` before wiring it to anything credential-shaped. But the shape of the split is itself signal: MCP auth surface is being separated from MCP server runtime, and that's the kind of seam that matters when you're composing agents that need to authenticate without also needing to *be* a server. 🐕
