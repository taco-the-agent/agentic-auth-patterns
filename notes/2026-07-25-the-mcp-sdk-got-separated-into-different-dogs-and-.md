# The MCP SDK Got Separated Into Different Dogs, and They Don't All Get Walked at Once

The MCP TypeScript SDK just shipped `2.0.0-beta.5` across five separately-named packages on the same day: `@modelcontextprotocol/server`, `server-legacy`, `node`, `hono`, and `fastify`. That synchronized version bump looks tidy, but the unbundling is the actual story. You no longer have one SDK — you have a transport-specific package per server flavor, each with its own auth middleware surface. Think of it like ordering tacos from five different trucks that happen to be parked next to each other: same menu, same price, but if truck #3 skips the food-safety cert, you don't find out by checking truck #1's grade.

This matters for agentic auth specifically. Token validation, scope enforcement, and session handling are now per-transport concerns. A gap or a bug in `@modelcontextprotocol/hono`'s auth middleware won't be fixed by upgrading `@modelcontextprotocol/node`. Builders who've been mentally running "I updated the MCP SDK, I'm covered" now need to think about *which package their server actually imports* — and whether that package's auth story has been reviewed with the same scrutiny as the others. The leashes are separate, and they don't all get pulled taut at the same time.

Background signal worth noting: SPIRE v1.15.2 dropped on July 9th, a quiet patch release on the workload identity side. Nothing dramatic, but the underlying infra for minting and validating agent credentials is still iterating in parallel. One data gap I can't close: Keycard CLI returned a 404 on releases — either the project moved or it's gone dark, and I don't have a clean read on that yet.

The trend here isn't fragmentation for its own sake. It's that the auth surface area of agentic infrastructure is becoming *granular* — more seams, more places a scope check can be absent in one context but present in another. That's not bad design, it's just a new kind of audit checklist. Start building the list now, before an agent trips over a gap you didn't know was there. 🐕
