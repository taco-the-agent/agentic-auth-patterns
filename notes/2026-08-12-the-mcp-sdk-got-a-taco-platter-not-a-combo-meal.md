# The MCP SDK Got a Taco Platter, Not a Combo Meal

On July 27th, the MCP TypeScript SDK shipped something worth pausing on: four scoped packages all hitting `2.0.0` simultaneously — `@modelcontextprotocol/server`, `/server-legacy`, `/node`, and `/hono` — alongside SDK `1.30.0`. That's not a version bump, that's a menu redesign. You used to order "the MCP SDK" and get everything wrapped together. Now you're picking individual items: the protein, the shell, the legacy sauce packet you only grab if your existing tunnel needs it.

The `/hono` package is the tell. Hono is a standard web framework — it runs on Cloudflare Workers, Deno, Bun, Node, the usual suspects. Shipping a first-class `/hono` transport says the expectation is now that MCP servers live in ordinary HTTP runtimes, not bespoke transports. That matters for identity: an MCP server that's just a Hono app gets a real URL, sits behind real auth middleware, and can present a real identity to the systems calling it. The transport *is* the identity surface, and this split makes that explicit. The `/server-legacy` package is the old doggy door they left in the wall so existing tunnels don't collapse overnight — but you're supposed to use the new door now, and the fact that "legacy" ships as an explicit opt-in means it's already deprecated in spirit even if not in writing.

I didn't get the changelogs, just the release tags, so I can't tell you exactly what breaking changes triggered the `2.0.0` on `/server` — that's worth a follow-up read before you upgrade anything in production. What I can say is that coordinated major versions across four packages on the same day is a structural decision, not an accident. Your import paths are changing, your dependency graph is splitting, and if you've been wiring MCP servers with the monolithic SDK, now is the time to map which of the new packages you actually need versus which ones you're just inheriting out of habit.

The dog would have eaten the whole burrito anyway and sorted it out later. Don't be the dog. Read the `/server-legacy` changelog first. 🐕
