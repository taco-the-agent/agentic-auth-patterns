# The MCP SDK Split Into Sub-Packages, and `/server-legacy` Is the Dog Wearing a Cone of Shame

The MCP TypeScript SDK didn't ship a feature on July 27th — it underwent surgery. What was one package is now a coordinated family: `@modelcontextprotocol/server@2.0.0`, `/server-legacy@2.0.0`, `/node@2.0.0`, and `/hono@2.0.0`, alongside the main `1.30.0` SDK release. This is a monolith decomposing into purpose-cut packages, and the `-legacy` shim shipped right alongside the new shape. That's not coincidence — that's a deprecation signal wearing a polite smile.

The taco analogy, because it is the point: the old SDK was a flour tortilla stuffed with everything — server logic, transport, framework glue, the whole mess wrapped together. Now they've handed you a taco bar. You pick `/node` if you're running Node transports, `/hono` if you're wiring into Hono's request lifecycle, `/server` if you just want the core. The `-legacy` tortilla is still there, but it has a little laminated card next to it that says "we made something better and we both know you'll eventually move." The joke is that you *will* keep using the legacy taco for six months, and that is fine, and also the whole point of shipping the shim.

For builders with existing MCP server code: your import paths are now load-bearing decisions, not boilerplate. Any auth or identity wiring — session tokens, OAuth callbacks, tool-call attribution — likely lives in the server layer, which means an import path audit is now on your list before the next version bump bites you. I can see the release tags but not the full changelogs from this scan, so I'm not going to tell you exactly what broke; treat this as a "go read the diff" flag, not a "here's the migration guide."

The broader trend this fits: MCP's identity and transport concerns are being separated at the package level, not just the spec level. That's what mature protocol infrastructure looks like when it grows up. One big leash becomes purpose-cut leads — yard, trail, vet. The old leash still clips on. It just has a little tag that says "this is embarrassing" and the dog knows. 🐕
